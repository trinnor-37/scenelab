# Behavioral Science Reference

Deep psychological framework for designing high-converting short-form video ads.

---

## The Attention & Emotion Pathway

Every effective ad follows this psychological sequence:

### 1. Stop-Scroll (0-1s)
**Goal:** Pattern interrupt in the feed

**Triggers:**
- Visual novelty (unexpected object, color, composition)
- Contrast (cold vs warm, messy vs clean, empty vs crowded)
- Emotionally charged micro-moment (surprise, tension, curiosity)
- Motion that breaks feed uniformity

**Principle:** The brain's reticular activating system flags novelty. Your first frame must be different enough to trigger attention capture.

### 2. Sustain (1-8s)
**Goal:** Keep viewer watching

**Mechanisms:**
- Curiosity gap: Open ONE question the viewer wants answered
- Visible progress: Show movement toward something interesting
- Escalation: Each moment slightly more engaging than the last
- Prediction error: Subvert expectations just enough to maintain interest

**Warning:** Multiple open loops create cognitive overload. Open ONE main curiosity loop.

### 3. Peak (8-15s)
**Goal:** Deliver emotional payoff

**Target Emotions (High-Arousal Positive):**
- **Joy/Humor:** Light, human moments, gentle self-deprecation
- **Awe:** Scale (big landscapes), skill (expert action), beauty (light, motion)
- **Inspiration:** "If they can, maybe I can"
- **Pleasant Surprise:** Twist that's uplifting, not cruel

**Product Integration:** Brand/product should appear AT or NEAR the peak, not after it.

### 4. Closure (15-20s)
**Goal:** Satisfaction + meaning

**Mechanisms:**
- Relief: Tension resolved
- Completion: Story has ending
- Meaning: Viewer feels "that was worth it"
- No fake "continued..." hooks

### 5. Memory & Share (Post-View)
**Goal:** Stick in memory, trigger sharing

**Mechanisms:**
- Simple, repeatable idea or image
- Satisfying loop (last shot connects to first)
- Social currency: Viewer looks good sharing this
- Practical value: Useful information worth passing on

## Curiosity & Hook Patterns

### Effective Hook Types

| Hook Type | Mechanism | Example |
|-----------|-----------|---------|
| **Bold Visual Contrast** | Pattern interrupt through opposition | Cold vs warm, messy vs clean |
| **Transformation Promise** | Clear before-after trajectory | "Watch this transform" |
| **Micro-Fail → Win** | Relatable struggle + satisfying solve | Small mistake, then success |
| **Hyper-Specific Benefit** | Concrete, measurable promise | "How I use X to do Y in 10 seconds" |
| **Incomplete Information** | Knowledge gap the brain wants closed | "The one thing nobody tells you..." |
| **Social Proof Trigger** | Evidence others have succeeded | "After 10,000 customers..." |

### Curiosity Rules

1. **Open ONE main loop** — Multiple loops create confusion
2. **Make payoff visible** — Viewer must see resolution coming
3. **No bait-and-switch** — Pay off exactly what you promised
4. **Front-load value** — Even if they leave early, they got something

### The Information Gap Theory

Curiosity = perception that we're missing information we want.

**To create curiosity:**
1. Show that information exists
2. Demonstrate its value
3. Make the gap small enough to feel closable
4. Provide clear path to closure (keep watching)

## Rhythm & Pattern Theory

### The Pattern-Violation-Resolution Model

The brain seeks patterns, enjoys their violation, and craves resolution:

```
PATTERN → VIOLATION → RESTORED PATTERN
```

**Application:**
- Establish visual/audio rhythm in first 3-5 seconds
- Violate it with unexpected element at 5-7 seconds
- Restore (evolved) pattern through 15-20 seconds

### Practical Rhythm Guidelines

| Element | Guideline |
|---------|-----------|
| **Shot pacing** | Alternate "progress" shots with "emotion" shots |
| **Beat repetition** | Don't repeat exact same beat >2x without evolution |
| **Energy curve** | Build → Peak → Resolve (not flat, not chaotic) |
| **Information density** | Vary high-info and low-info moments |

### Too Predictable vs Too Random

| Problem | Symptom | Fix |
|---------|---------|-----|
| **Too predictable** | Viewer skips ahead mentally | Add unexpected element at 40-60% mark |
| **Too random** | Viewer can't follow, drops off | Establish clearer pattern in first 3s |

## Memory & Branding Techniques

### Making Ads Memorable

**Technique 1: Repetition of Motif**
Repeat a simple phrase, gesture, or visual element:
- Specific hand gesture (sip, shrug, glance)
- Repeated object (can, bottle, phone, door)
- Environmental motif (same window, mountain view, neon sign)

**Technique 2: Peak-Product Association**
Place brand/product AT the emotional peak:
- Not before (viewer hasn't reached emotional state)
- Not after (emotional decay has begun)
- During (maximum association strength)

**Technique 3: Loop-Friendly Structure**
Last shot conceptually connects to first:
- Same location, different state (messy → clean)
- Same action, reversed outcome
- Visual rhyme (color, composition, subject position)

### The Peak-End Rule

People remember:
1. The emotional peak (strongest moment)
2. The ending (final impression)

**Implication:** Invest heavily in your peak moment and closing shot. The middle can be simpler.

## Emotional Valence Selection

### High-Arousal Positive (Preferred)

| Emotion | Best For | Execution |
|---------|----------|-----------|
| **Joy** | Mass appeal, shareable | Light moments, human connection |
| **Humor** | Engagement, memorability | Self-deprecation, situational comedy |
| **Awe** | Premium brands, inspiration | Scale, beauty, skill demonstration |
| **Inspiration** | Transformation products | "If they can, I can" narratives |
| **Pleasant Surprise** | Differentiation, virality | Uplifting twists, unexpected positive |

### When to Use Negative Emotions (Carefully)

| Emotion | When to Use | Guard Rails |
|---------|-------------|-------------|
| **Fear** | Problem-aware audiences, safety products | Always pair with clear solution |
| **Frustration** | Pain-point products | Show empathy, not mockery |
| **FOMO** | Limited offers, community products | Keep honest, avoid manipulation |

**Rule:** Any negative emotion must resolve to positive by the end.

## Cultural Considerations

### Safer Global Anchors

These themes travel well across cultures:
- **Curiosity** — Universal human drive
- **Kindness** — Cross-cultural positive
- **Music** — Emotional without language barriers
- **Kids/Animals** — Used respectfully, universal appeal
- **Personal triumph** — Achievement is relatable everywhere
- **Everyday struggles** — Shared human experience

### Avoid Unless User-Guided

- Religious imagery or themes
- Political content or figures
- Highly local taboos or customs
- Cultural-specific humor that may not translate

### Humor Guidelines

**DO:**
- Gentle self-deprecation
- Situational comedy
- Universal human moments
- Clever wordplay (if translatable)

**DON'T:**
- Mock groups or identities
- Physical trait humor
- Sarcasm (doesn't translate well)
- Culture-specific references without context

## Metrics as Mental Targets

Use these benchmarks to self-check concepts (don't output unless asked):

| Metric | Target | Self-Check Question |
|--------|--------|---------------------|
| **3-second retention** | >70% | Is hook visually distinct + immediately meaningful? |
| **Completion rate** | >50% | Does every shot add new value or step? |
| **Rewatch rate** | >10% | Is there a loop-friendly structure or easter egg? |
| **Share rate** | >2% | Would viewer look good sharing this? |

### The "Filler Shot" Test

For each shot, ask: "If I removed this, would the ad still work?"
- If yes → Consider cutting
- If no → Keep and strengthen

## Improving Existing Ideas

When user provides a rough concept, analyze:

### Diagnosis Framework

| Question | If Weak | Fix |
|----------|---------|-----|
| What's the hook? | Unclear or generic | Make Shot 1 more visually surprising |
| Where's the emotional peak? | Missing or scattered | Consolidate into one clear payoff |
| Is there closure? | Abrupt or missing | Add resolution + light CTA |
| Does it loop? | No connection | Make last shot echo first |

### Improvement Protocol

1. **Tighten the middle** — Remove any beat that doesn't escalate or clarify
2. **Strengthen the hook** — More visual contrast, more specific benefit
3. **Focus the peak** — One clear payoff, not several noisy moments
4. **Clarify the CTA** — Low-pressure, aligned with the story

## The Complete Psychological Checklist

Before finalizing any storyboard:

- [ ] **Hook** creates genuine curiosity (not trick or confusion)
- [ ] **One main loop** opened and closed
- [ ] **Peak emotion** is high-arousal positive
- [ ] **Product appears** at or near emotional peak
- [ ] **Every shot** adds value (no filler)
- [ ] **Rhythm** varies predictably (pattern-violation-pattern)
- [ ] **Ending** provides closure and meaning
- [ ] **Loop potential** exists (last connects to first)
- [ ] **CTA** is honest and low-pressure
- [ ] **Cultural safety** checked for target audience
