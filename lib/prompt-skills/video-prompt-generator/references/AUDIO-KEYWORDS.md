# Audio & Performance Keywords Reference

Complete reference for triggering specific audio behaviors across modern director-controllable video models. These keywords are universal — they work the same way in any video model that supports native audio generation.

If your model supports audio reference uploads, you can attach a track for beat-synced mood control. Match the cut rhythm of your shot blocks to the reference audio's beat pattern for tighter audio-visual sync.

## Voice Tone Descriptors

Use these in dialogue attribution for precise emotional delivery:

### Positive Tones
- warm, gentle, cheerful, friendly, excited, enthusiastic
- calm, soothing, reassuring, tender, affectionate
- confident, proud, triumphant, playful, amused

### Negative Tones
- angry, frustrated, annoyed, irritated, bitter
- sad, melancholic, grieving, heartbroken, disappointed
- scared, nervous, anxious, terrified, panicked
- cold, distant, dismissive, sarcastic, contemptuous

### Neutral/Complex Tones
- controlled, measured, professional, matter-of-fact
- hesitant, uncertain, contemplative, thoughtful
- tired, exhausted, resigned, defeated
- curious, intrigued, surprised, shocked

### Voice Quality Descriptors
- raspy, deep, high-pitched, soft, loud
- trembling, cracking, steady, clear, muffled
- accented, slightly accented, regional dialect

## Pacing Keywords

Use between dialogue lines to control rhythm:

- `Immediately,` - Quick response, no pause
- `Pause.` - Brief beat of silence
- `Silence.` - Extended pause, tension
- `Beat.` - Dramatic pause
- `A moment passes.` - Reflective pause
