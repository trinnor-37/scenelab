# Higgsfield Cinema Studio 2 — Quick Reference

## Camera Decision Tree

```
Need clean/commercial?    → Modular 8K Digital
Need cinematic default?   → Full-Frame Cine Digital ⭐
Need indie/character?     → Studio Digital S35
Need epic/scale?          → Grand Format 70mm Film
Need raw/textured?        → Classic 16mm Film
Need premium depth?       → Premium Large Format
```

```
Need horror/scale/chaos?  → 8–14mm
Need dialogue/versatile?  → 24–35mm ⭐
Need intimate/character?  → 50mm
Need portrait/isolation?  → 85mm+
```

## Aperture Decision Tree

```
Need subject isolation?   → f/1.4–f/2
Need balanced scene?      → f/4–f/5.6 ⭐
Need everything sharp?    → f/8–f/11
```
